# 2026-07-28

## Windows 平台移植 + GitHub Actions CI

为 drop-typing 项目添加了 Windows 平台支持和 GitHub Actions 打包工作流：

### 新增文件
- `.github/workflows/build-windows.yml` — Windows CI 工作流（push/PR/tag 触发，构建 + artifact 上传 + tag 时创建 Release）
- `src-tauri/src/hotkey/windows.rs` — Windows 热键实现（rdev 低级键盘钩子，Right Win/Alt/Shift）
- `src-tauri/src/inject/windows.rs` — Windows 文字注入（arboard 剪贴板 + enigo Ctrl+V）

### 修改文件
- `Cargo.toml` — rdev/enigo/arboard 从 macOS target deps 移到通用 deps（跨平台 crate）
- `hotkey/mod.rs` — 添加 `#[cfg(target_os = "windows")]` 分支
- `inject/mod.rs` — 添加 `#[cfg(target_os = "windows")]` 分支
- `lib.rs` — `caret` 模块加 `#[cfg(target_os = "macos")]` 守卫（使用 core-foundation/core-graphics）

### 关键设计决策
- Windows 粘贴用 Ctrl+V（macOS 用 Cmd+V）
- `Modifier::Command` 在 Windows 上映射为 Ctrl（Windows 无 Cmd 键）
- Windows 不需要主线程调度（macOS 26 TSM 约束是 macOS 专属）
- Windows 低级键盘钩子无需辅助功能权限
- vendored rdev 补丁只改 macOS 代码，Windows 编译不受影响

### 待办
- `tauri.conf.json` 当前 `"targets": "app"` 只产出裸 .exe，如需 NSIS/MSI 安装包需改为 `"nsis"` 或 `"all"`
- `command/mod.rs` 的 `Modifier` 枚举仍为 macOS 语义（Command/Option），Windows 语音指令词表可能需要调整
- 透明窗口在 Windows 上的渲染效果需实际测试
